# DigitalSoft RD — SistemaInventario
Proyecto de escritorio para la gestión de productos, desarrollado con C#, Windows Forms y SQL Server.

## Avance reportado
- Conexión de la aplicación con SQL Server.
- Visualización de productos en una tabla.
- Operaciones de creación, consulta, edición, eliminación y búsqueda de productos.

Estas capacidades corresponden al avance reportado durante el desarrollo; no se volvieron a ejecutar en esta revisión del portafolio.

## Próxima validación
Identificar y ejecutar el proyecto que se publicará, documentar los requisitos y demostrar el ciclo completo de un producto con datos ficticios.

Categorías, proveedores, entradas/salidas y facturación no se presentan como funciones terminadas en esta ficha: requieren verificar la versión seleccionada.

El repositorio propuesto es una presentación del producto; el código comercial se conserva por separado.
