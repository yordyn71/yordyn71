# DigitalSoft RD — Alquileres
Software de gestión de alquileres orientado a propietarios y administradores.

## Estado
Proyecto comercial con una edición para Windows. Su instalación y funcionamiento mediante instalador fueron confirmados por el autor. Esta ficha es una presentación inicial; el paquete concreto y su alcance funcional deben identificarse antes de publicar una demostración.

## Objetivo
Organizar la información y el seguimiento de la actividad de alquileres en una herramienta de gestión.
