# DigitalSoft RD — Portafolio Excel
Espacio propuesto para ejemplos de análisis empresarial con Excel.

## Casos que se prepararán
- Comparativo de ventas por período y vendedor.
- Resumen de cuentas por cobrar y antigüedad de saldos.
- Seguimiento de pedidos y fechas de entrega.

## Estado
Contenido en preparación. No hay archivos de demostración incluidos ni resultados publicados en esta ficha.

Cada ejemplo debe incluir datos sintéticos, diccionario de campos, fórmulas documentadas, explicación de indicadores y una captura del resultado. Las fórmulas dirigidas al usuario se documentarán para Excel en español.

No se publicarán informes internos, nombres de clientes, facturas ni carteras reales. Power BI se mantiene como área de formación hasta contar con un proyecto verificable.
